## 字段规范（questions_v2.0.jsonl）

| 字段 | 说明 |
|---|---|
| `id` | q001–q238 |
| `type` | 事实型/对比型/过程型/多跳型/计算型（规则自动分类） |
| `question` | 题面（选择题含选项；填空题以 ____ 表示空位） |
| `gold_answer` | 标准答案（选择题为「字母. 选项文本」） |
| `gold_evidence` | 语料原文逐字片段（仅 v1.0 30 题保留） |
| `gold_chunks` | chunk_id 列表，命中判定以 chunk_id 为准 |
| `key_points` | 答案关键点（自动抽取） |
| `options` / `answer_letter` | 选择题选项与答案字母（仅选择题） |
| `source` | 题目来源 |

## 自动质检（auto-audit，取代人工抽检）

- A1 去重：归一化精确去重 + token Jaccard>0.7 近重复，共丢弃 66；
- A2 gold 映射：题干+答案与 chunk 的 idf 加权 token 重叠，阈值 6.0，映射失败即弃；
- A3 答案支撑：gold chunk 与标准答案 token 重叠率，选择题 ≥0.15、问答/填空 ≥0.30，共丢弃 81；
- A4 时代/缺图过滤：windows95/netware/RS-232C/活动目录等知识库外题与引用插图的题，共丢弃 27。

报告见 `data/eval/audit_report_v2.0.md`；清单与 sha256 见 `data/eval/eval_v2.0_manifest.json`。

## Baseline v2.0 完整评测结果（238 题，2026-10-07）

配置：chunk_size=512 / overlap=50 / dense(nomic-embed-text) / top_k=5 / qwen3:4b；耗时 24481.7s（6h48m）。

| 指标 | @1 | @3 | @5 | @10 | @20 | @50 |
|---|---|---|---|---|---|---|
| HitRate | 0.067 | 0.193 | 0.265 | 0.357 | 0.479 | 0.656 |
| Recall  | 0.038 | 0.108 | 0.153 | 0.218 | 0.324 | 0.476 |

| 生成与整体指标 | 值 |
|---|---|
| MRR | 0.164 |
| KeyPointCoverage | 0.494 |
| CitationRate | 0.500 |
| Faithfulness | 0.339 |

| 失败类型 | 占比 | 题数 |
|---|---|---|
| `rank_miss`（top-50 内但不在 top-5） | 39.1% | 93 |
| `retrieval_miss`（top-50 内无 gold） | 34.5% | 82 |
| `ok` | 21.4% | 51 |
| `generation_miss`（检索到但答案覆盖不足） | 5.0% | 12 |

> 结论：**排序是首要瓶颈**（`rank_miss` 39.1% > `retrieval_miss` 34.5%，HitRate@5 与 @50 差 0.39），rerank 是收益最大的优化方向；详见 `results/baseline_v2/`（summary.json + per_question.csv）与 issues I09/I10。
